# 快速入门：运行你的第一批测试

本指南带你在几分钟内从零开始，完成第一次成功的测试运行。

## 概览

```mermaid
flowchart LR
    A["1. 创建项目"] --> B["2. 网站扫描"]
    B --> C["3. 生成测试"]
    C --> D["4. 运行测试"]
    D --> E["5. 查看结果"]
```

## 第 1 步：创建项目

1. 前往**控制台 → 项目 → 新建项目**
2. 输入你要测试的环境的**基础 URL**
3. 如有需要登录的流程，可选择添加**登录凭据**

### 建议

| 设置项 | 建议 |
| :---------------- | :---------------------------------------------------- |
| **环境** | 使用稳定的预发布环境 |
| **双重验证（2FA）/ 验证码** | 在测试环境中关闭，确保自动化稳定可靠 |
| **测试账户** | 创建一个具备必要权限的专用账户 |

## 第 2 步：添加用户旅程

你有两种方式为项目填充测试场景：

### 方式 A：网站扫描（自动发现）

启动**网站扫描**，让 AI 智能体探索你的网站，发现关键的用户流程。

| 流程类型 | 示例 |
| :--------------- | :--------------------------------- |
| 身份验证 | 登录、退出登录、重置密码 |
| CRUD 操作 | 创建、读取、更新、删除条目 |
| 搜索和筛选 | 搜索栏、分面导航 |
| 仪表盘 | 数据分析、报告、管理后台 |

### 方式 B：上传 PRD（基于文档）

如果你已有需求文档，可以上传它们，自动提取测试场景。

1. 点击**从 PRD 添加用户旅程**
2. 上传你的 PRD 文件（PDF、DOC、DOCX 或 TXT）
3. 等待 AI 提取场景
4. 审阅并批准生成的用户旅程

| 何时使用 PRD 上传 | 好处 |
| :---------------------------------- | :------------------------------ |
| 你有详细的需求文档 | 比手动录入更快 |
| 测试特定功能 | 测试覆盖更有针对性 |
| 启动新项目 | 充分利用现有文档 |

详细指南请参阅[上传 PRD 文件](concepts/prd-upload.md)。

### 方式 C：根据指令生成

用自然语言描述你想测试的内容，让 AI 生成用户旅程。

1. 点击**添加用户旅程**，然后选择**根据指令生成**
2. 写下用户流程的描述（例如“用户登录、查看仪表盘，然后更新个人资料”）
3. 点击**生成预览**
4. 审阅并编辑生成的用户旅程
5. 点击**添加到测试计划**

详细指南请参阅[根据指令生成](concepts/generating-from-instructions.md)。

### 管理已发现的流程

| 操作 | 使用时机 |
| :------------- | :--------------------------------- |
| **重命名** | 与你所在领域的用语保持一致 |
| **停用** | 排除你不关心的流程 |
| **设为优先** | 标记关键业务流程 |

## 第 3 步：生成并运行测试

1. 选择你最关心的流程
2. 点击**生成测试**
3. 脚本就绪后，点击**全部运行**

### 运行期间会发生什么

| 步骤 | 说明 |
| :------------ | :------------------------------------------ |
| 打开浏览器 | 启动真实的浏览器环境 |
| 执行步骤 | 依次运行脚本中的每个操作 |
| 验证 | 由断言检查预期结果 |
| 捕获 | 保存截图和日志，便于调试 |

## 第 4 步：查看结果

运行完成后，打开项目的**报告**标签页。

### 筛选结果

| 筛选条件 | 用途 |
| :------------- | :------------------------------- |
| **状态** | 仅显示通过或失败的测试 |
| **流程名称** | 聚焦于特定的用户旅程 |
| **日期范围** | 比较不同时间的结果 |

### 排查失败

对于每个失败的步骤，你可以看到：

| 信息 | 用途 |
| :---------------- | :------------------------------ |
| **操作** | 失败的具体步骤 |
| **截图** | 失败时的页面视觉状态 |
| **错误消息** | 用于调试的技术细节 |
| **页面网址** | 失败发生的位置 |
