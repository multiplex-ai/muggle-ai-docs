# API 概览

你可以使用 Muggle Test API，以编程方式触发运行并获取结果。

> 以编程方式触发和读取测试运行，使用的是 `/v1/protected/muggle-test/...` 下的批量回放调用序列。端点详情请参阅[通过 API 运行测试](api/running-tests-via-api.md)，完整的流水线示例请参阅 [CI/CD 集成](mcp/mcp-cicd-integration.md)。

## 使用场景

| 场景 | API 的作用 |
| :---------------- | :--------------------------------------- |
| CI/CD 集成 | 每次部署时触发测试 |
| 冒烟测试 | 在发布前后运行关键测试 |
| 自定义仪表盘 | 基于测试结果构建报告 |
| 定时运行 | 自动执行每晚的回归测试 |

## 身份验证

所有 API 请求都需要通过 **Bearer token** 或 **API 密钥**进行身份验证。

### Bearer Token

```http
Authorization: Bearer YOUR_API_KEY
```

### API 密钥请求头

```http
x-api-key: YOUR_API_KEY
```

### 获取你的 API 密钥

1. 前往**控制台 → 设置 → API 密钥**
2. 点击**创建 API 密钥**
3. 复制并妥善保存（格式：`mai_sk_...`）

> **安全**：切勿将 API 密钥提交到版本控制系统，也不要在客户端代码中暴露它们。

## 基础 URL

```text
https://promptservice.muggle-ai.com
```

本文档中的所有端点都相对于此基础 URL。

## 通用模式

| 方法 | 用途 | 示例 |
| :------- | :---------------- | :------------------------ |
| `GET` | 检索实体 | 列出项目、获取运行记录 |
| `POST` | 创建或触发 | 启动测试运行 |
| `PUT` | 更新实体 | 修改项目设置 |
| `DELETE` | 删除实体 | 删除测试脚本 |

## 请求/响应格式

| 方面 | 标准 |
| :----------------- | :-------------------------------- |
| 内容类型 | `application/json` |
| 字符编码 | UTF-8 |
| 日期格式 | ISO 8601（`2024-01-15T10:30:00Z`） |

## 错误处理

| 状态码 | 含义 | 处理方式 |
| :---------: | :----------- | :----------------------------- |
| 200 | 成功 | 处理响应 |
| 400 | 请求错误 | 检查请求参数 |
| 401 | 未授权 | 核对 API 密钥 |
| 403 | 禁止访问 | 检查权限 |
| 404 | 未找到 | 核对资源 ID |
| 429 | 请求频率超限 | 退避后重试 |
| 500 | 服务器错误 | 使用指数退避重试 |

## 速率限制

| 档位 | 每分钟请求数 |
| :--------- | --------------: |
| 免费版 | 20 |
| 入门版 | 40 |
| 专业版 | 60 |
| 企业版 | 300 |

响应中会包含速率限制响应头：

| 响应头 | 说明 |
| :---------------------- | :-------------------------- |
| `X-RateLimit-Limit` | 允许的最大请求数 |
| `X-RateLimit-Remaining` | 剩余请求数 |
| `X-RateLimit-Reset` | 重置时间（Unix 时间戳） |
