# API 總覽

你可以使用 Muggle Test API，以程式方式觸發執行並取得結果。

> 以程式方式觸發與讀取測試執行，使用的是 `/v1/protected/muggle-test/...` 底下的批次重播呼叫序列。端點詳細資訊請參閱[透過 API 執行測試](api/running-tests-via-api.md)，完整的管線範例請參閱 [CI/CD 整合](mcp/mcp-cicd-integration.md)。

## 使用情境

| 情境 | API 的用途 |
| :---------------- | :--------------------------------------- |
| CI/CD 整合 | 每次部署時觸發測試 |
| 冒煙測試 | 在發布前後執行關鍵測試 |
| 自訂儀表板 | 以測試結果為基礎建立報告 |
| 排程執行 | 自動執行每晚的迴歸測試 |

## 身分驗證

所有 API 請求都必須透過 **Bearer token** 或 **API 金鑰**進行身分驗證。

### Bearer Token

```http
Authorization: Bearer YOUR_API_KEY
```

### API 金鑰標頭

```http
x-api-key: YOUR_API_KEY
```

### 取得你的 API 金鑰

1. 前往**儀表板 → 設定 → API 金鑰**
2. 點選**建立 API 金鑰**
3. 複製並妥善保管（格式：`mai_sk_...`）

> **安全性**：切勿將 API 金鑰提交到版本控制系統，也不要在用戶端程式碼中公開金鑰。

## 基礎 URL

```text
https://promptservice.muggle-ai.com
```

本文件中的所有端點都是相對於此基礎 URL。

## 通用模式

| 方法 | 用途 | 範例 |
| :------- | :---------------- | :------------------------ |
| `GET` | 擷取實體 | 列出專案、取得執行記錄 |
| `POST` | 建立或觸發 | 啟動測試執行 |
| `PUT` | 更新實體 | 修改專案設定 |
| `DELETE` | 移除實體 | 刪除測試腳本 |

## 請求/回應格式

| 項目 | 標準 |
| :----------------- | :-------------------------------- |
| 內容類型 | `application/json` |
| 字元編碼 | UTF-8 |
| 日期格式 | ISO 8601（`2024-01-15T10:30:00Z`） |

## 錯誤處理

| 狀態碼 | 意義 | 處理方式 |
| :---------: | :----------- | :----------------------------- |
| 200 | 成功 | 處理回應 |
| 400 | 錯誤的請求 | 檢查請求參數 |
| 401 | 未授權 | 確認 API 金鑰 |
| 403 | 禁止存取 | 檢查權限 |
| 404 | 找不到 | 確認資源 ID |
| 429 | 超出速率限制 | 稍候再重試 |
| 500 | 伺服器錯誤 | 以指數退避方式重試 |

## 速率限制

| 等級 | 每分鐘請求數 |
| :--------- | --------------: |
| 免費版 | 20 |
| 入門版 | 40 |
| 專業版 | 60 |
| 企業版 | 300 |

回應中會包含速率限制標頭：

| 標頭 | 說明 |
| :---------------------- | :-------------------------- |
| `X-RateLimit-Limit` | 允許的最大請求數 |
| `X-RateLimit-Remaining` | 剩餘請求數 |
| `X-RateLimit-Reset` | 重設時間（Unix 時間戳記） |
