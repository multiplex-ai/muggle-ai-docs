# 訂閱方案

Muggle Test 提供多種訂閱等級，以符合你的測試需求。每個方案都包含每個專案無限量的使用者旅程與測試案例；用量以 Token 計量。

如需了解目前價格，請參閱[定價頁面](https://muggle-ai.com/#pricing)或產品目錄 API。

## 同時執行的工作流程

此限制決定可以同時執行多少個工作流程（掃描、測試產生、重播）。

| 方案 | 同時執行上限 |
| :--- | :--------------- |
| 免費版 | 3 |
| 入門版 | 10 |
| 專業版 | 20 |
| 企業版 | 20+ |

如果在已達上限時啟動工作流程，它會等待某個執行中的工作流程結束。會等待多久，請參閱[配額與限制](billing/quotas-and-limits.md)。

## 查看目前用量

在儀表板中開啟**帳單**，即可查看你的 Token 餘額與同時執行的工作流程用量。

## 每月 Token 贈送額度

方案中包含的 Token 額度會計入你錢包的**贈送餘額**。各等級的運作方式如下：

- **免費版：** 免費版使用者在註冊時會獲得**一次性**的 100 萬 Token 贈送額度。這筆額度**永遠不會重新補充**——用完後，可以改用入門版（開放所有使用者使用，驗證電子郵件後即可使用，每月補滿至 300 萬 Token），或升級到付費方案。免費版使用者沒有每月重置。
- **入門版與專業版：** 每次 Stripe 訂閱發票付款成功後，你錢包的贈送餘額都會**補足至方案額度**。上個週期剩餘的贈送額度**不會**累加到新一個月的額度——贈送餘額只會補足至方案額度（絕不會減少）。你以加值方式購買的 Token 會分開記錄，永不過期。
- **企業版：** 企業組織錢包**沒有**每月贈送額度。Token 用量透過 Stripe 以每 100 萬 Token $5 計量，並在每張發票中結算。企業組織錢包的贈送餘額在結構上一律為 0。
- **方案升級：** 在週期中途升級時（例如入門版 → 專業版），Stripe 開立按比例計費的發票後，你的錢包會立即獲得新舊方案額度之間的**差額**（例如，在週期中途從入門版升級到專業版，會計入 1700 萬 = 2000 萬 − 300 萬）。降級**絕不會收回 Token**。
- **Token 扣抵順序：** 使用 Token 時，會**先扣除贈送餘額**，再扣除你購買的 Token 加值包。這對購買加值包的使用者比較公平，因為贈送的 Token 本來就可能在續訂時重置。

### 購買的 Token 加值包

如果你需要的 Token 超過方案贈送的額度，可以在帳單頁面購買一次性的 Token 加值包。**以這種方式購買的 Token 永不過期**，並與方案贈送額度分開記錄在獨立的餘額中。變更方案、續訂與降級後，這些 Token 依然保留。

## 升級方案

若要提高上限：

1. 前往儀表板中的**帳單**
2. 選取**帳單**分頁
3. 點選**變更方案**
4. 選擇新方案

變更會立即生效，新的上限適用於所有現有專案。

## 企業版

企業版專為團隊打造。不必讓每位工程師各自付費訂閱，你的公司會取得一個擁有席位池的**組織**，可以邀請團隊成員，並共用同一筆 Token 餘額與同一組專案。企業版無法透過自助結帳開通。

**定價**

- **每個席位每月 $60**，至少 **4 個席位**（每月最低 $240）。
- **Token 按用量計費，每 100 萬 Token $5**，在每個帳單週期結束時加總，並計入同一張發票。企業組織錢包沒有每月贈送額度——所有 Token 消耗都完全按用量計費，透過 Stripe 計量。
- 席位數量可以調整。新增的席位按比例計費。

**包含內容**

- 20+ 個同時執行的工作流程，可依需求提高
- 共用的組織錢包與統一彙整的 Token 用量
- 用於存取控制的成員角色（擁有者、管理員、成員）
- 依成員與依專案進行成本歸屬
- CI/CD 整合

**個人帳戶不受影響**。加入組織不會改變你的個人訂閱、個人專案或個人錢包。兩者的計費完全獨立。完整說明請參閱[企業組織指南](enterprise-organizations.md)，包括專案歸屬如何決定計費，以及單一使用者如何同時隸屬於多個組織。

如需大量採購折扣或由業務協助設定，請透過 [sales@muggle-ai.com](mailto:sales@muggle-ai.com) 與我們聯絡。
