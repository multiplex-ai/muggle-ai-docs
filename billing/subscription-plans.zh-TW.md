Muggle Test 提供多種訂閱等級，以符合你的測試需求。每個方案都包含每個專案無限量的使用者旅程與測試案例；用量以 Token 計量。

如需了解目前價格，請參閱[定價頁面](https://muggle-ai.com/#pricing)或產品目錄 API。

## 同時執行的工作流程

此限制決定可以同時執行多少個工作流程（掃描、測試產生、重播）。

| 方案 | 同時執行上限 |
| :--- | :--------------- |
| 免費版 | 2 |
| 入門版 | 3 |
| 專業版 | 20 |
| 企業版 | 每個同時執行區塊 20 個，由整個組織共用 |

如果在已達上限時啟動工作流程，它會等待某個執行中的工作流程結束。會等待多久，請參閱[配額與限制](billing/quotas-and-limits.md)。

## 查看目前用量

在儀表板中開啟**帳單**，即可查看你的 Token 餘額與同時執行的工作流程用量。

## 每月 Token 贈送額度

方案中包含的 Token 額度會計入你錢包的**贈送餘額**。各等級的運作方式如下：

- **免費版：** 免費版使用者在註冊時會獲得**一次性**的 200 萬 Token 贈送額度。這筆額度**永遠不會重新補充**——用完後，可以改用入門版（開放所有使用者使用，驗證電子郵件後即可使用，每月補滿至 150 萬 Token），或升級到付費方案。免費版使用者沒有每月重置。
- **入門版與專業版：** 每次 Stripe 訂閱發票付款成功後，你錢包的贈送餘額都會**補足至方案額度**。上個週期剩餘的贈送額度**不會**累加到新一個月的額度——贈送餘額只會補足至方案額度（絕不會減少）。你以加值方式購買的 Token 會分開記錄，永不過期。
- **企業版：** 組織錢包**沒有**贈送額度。組織預先購買 Token，組織專案上的工作會從這筆預付餘額扣除。
- **方案升級：** 在週期中途升級時（例如入門版 → 專業版），Stripe 開立按比例計費的發票後，你的錢包會立即獲得新舊方案額度之間的**差額**（例如，在週期中途從入門版升級到專業版，會計入 1850 萬 = 2000 萬 − 150 萬）。降級**絕不會收回 Token**。
- **Token 扣抵順序：** 使用 Token 時，會**先扣除贈送餘額**，再扣除你購買的 Token 加值包。這對購買加值包的使用者比較公平，因為贈送的 Token 本來就可能在續訂時重置。

### 購買的 Token 加值包

如果你需要的 Token 超過方案贈送的額度，可以在帳單頁面購買一次性的 Token 加值包。**以這種方式購買的 Token 永不過期**，並與方案贈送額度分開記錄在獨立的餘額中。變更方案、續訂與降級後，這些 Token 依然保留。

## 升級方案

若要提高上限：

1. 前往儀表板中的**帳單**
2. 選取**帳單**分頁
3. 點選**變更方案**
4. 選擇新方案

變更會立即生效，新的上限適用於所有現有專案。

## 企業版

企業版專為團隊打造。你的公司會取得一個**組織**，擁有共用的專案、一筆預付 Token 餘額，以及一個同時執行工作流程的共用池。在定價頁面或儀表板的**帳單**頁面選擇**建立組織**，再到組織的**容量**頁面訂閱即可，不必與業務通話。

**定價**

- **貢獻者席位：** 第 1–10 個席位每個席位每月 $29，第 11–50 個席位 $24，第 51 個席位起 $19，至少 **3 個席位**。每位擁有者、管理員與貢獻者各占用一個席位；僅檢視的成員不占席位。
- **同時執行區塊：** 每個區塊含 20 個同時執行的工作流程，每月 $99，至少 1 個。最多 3 個區塊可自助購買；更多請洽業務。
- **Token：** 預付，每 100 萬 Token $5，每次購買 $100 起，並提供自動加值。沒有每月贈送額度。
- 新增的席位與區塊會立即生效並按比例計費；減少則在下次續訂時生效。

**包含內容**

- 整個組織共用一個同時執行工作流程的共用池，共用執行器忙碌時可優先啟動
- 共用的組織專案與預付的組織 Token 餘額
- 用於存取控制的成員角色（擁有者、管理員、貢獻者、成員）
- 每個專案的同時執行數量與每月 Token 上限
- 依成員與依專案區分的用量
- CI/CD 整合

**個人帳戶不受影響**。加入組織不會改變你的個人訂閱、個人專案或個人錢包。兩者的計費完全獨立。完整說明請參閱[企業組織指南](billing/enterprise-organizations.md)，包括專案歸屬如何決定計費，以及單一使用者如何同時隸屬於多個組織。

如需 3 個以上的同時執行區塊或由業務協助設定，請透過 [sales@muggle-ai.com](mailto:sales@muggle-ai.com) 與我們聯絡。
