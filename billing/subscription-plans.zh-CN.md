# 订阅套餐

Muggle Test 提供多个订阅档位，以满足你的测试需求。每个套餐都包含每个项目无限量的用户旅程和测试用例；用量以 Token 计量。

如需了解当前价格，请参阅[定价页面](https://muggle-ai.com/#pricing)或产品目录 API。

| 功能 | 免费版 | 入门版 | 专业版 | 企业版 |
| :------ | :--- | :------ | :----------- | :--------- |
| **并发工作流** | 3 | 10 | 20 | 20+ |
| **包含的 Token** | 100 万（一次性发放） | 每月 300 万 | 每月 2000 万 | 按量付费（每 100 万 Token $5） |
| **价格** | $0 | $0——验证邮箱即可解锁 | $199/月 | $60/席位/月（最少 4 个席位） |
| **席位** | 1 | 1 | 1 | 按购买数量（最少 4 个） |
| **共享团队工作区** | — | — | — | 是 |
| **CI/CD 集成** | — | — | 是 | 是 |
| **Token 购买** | — | 是（每 100 万 Token $5） | 是（每 100 万 Token $5） | 已包含（按量计费） |

## 并发工作流

此项限制决定可以同时运行多少个工作流（扫描、测试生成、回放）。

| 套餐 | 并发上限 |
| :--- | :--------------- |
| 免费版 | 3 |
| 入门版 | 10 |
| 专业版 | 20 |
| 企业版 | 20+ |

如果在已达上限时启动工作流，它会等待某个正在运行的工作流结束。等待时长请参阅[配额与限制](billing/quotas-and-limits.md)。

## 查看当前用量

在控制台中打开**账单**，即可查看你的 Token 余额和并发工作流用量。

## 每月 Token 赠送额度

套餐中包含的 Token 额度会计入你钱包的**赠送余额**。它在各档位中的规则如下：

- **免费版：** 免费版用户在注册时获得**一次性**的 100 万 Token 赠送额度。该额度**永不刷新**——用完后，可以改用入门版（向所有用户开放，验证邮箱后即可使用，每月补满至 300 万 Token），或升级到付费套餐。免费版用户没有每月重置。
- **入门版和专业版：** 每次 Stripe 订阅发票付款成功后，你钱包的赠送余额都会**补足到套餐额度**。上个周期剩余的赠送额度**不会**叠加到新一个月的额度上——赠送余额只会补足到套餐额度（绝不会减少）。你以充值方式购买的 Token 单独记录，永不过期。
- **企业版：** 企业组织钱包**没有**每月赠送额度。Token 用量通过 Stripe 按每 100 万 Token $5 计量，并在每张发票中结算。企业组织钱包的赠送余额在结构上始终为 0。
- **套餐升级：** 在周期中途升级时（例如入门版 → 专业版），Stripe 开具按比例计费的发票后，你的钱包会立即获得新旧套餐额度之间的**差额**（例如，在周期中途从入门版升级到专业版会计入 1700 万 = 2000 万 − 300 万）。降级**绝不会收回 Token**。
- **Token 消耗顺序：** 使用 Token 时，**先扣除赠送余额**，再扣除你购买的 Token 充值包。这对购买充值包的用户更公平，因为赠送的 Token 本来就可能在续订时被重置。

### 购买的 Token 充值包

如果你需要的 Token 超出套餐赠送的额度，可以在账单页面购买一次性的 Token 充值包。**以这种方式购买的 Token 永不过期**，并与套餐赠送额度分开记录在单独的余额中。更换套餐、续订和降级后，这些 Token 依然保留。

## 升级套餐

要提高上限：

1. 在控制台中进入**账单**
2. 选择**账单**标签页
3. 点击**更改套餐**
4. 选择新套餐

更改会立即生效，新的上限适用于所有现有项目。

## 企业版

企业版专为团队打造。不必让每位工程师各自付费订阅，你的公司会获得一个拥有席位池的**组织**，可以邀请团队成员，并共享同一个 Token 余额和同一组项目。企业版无法通过自助结账开通。

**定价**

- **每个席位每月 $60**，最少 **4 个席位**（每月最低 $240）。
- **Token 按量付费，每 100 万 Token $5**，在每个账单周期结束时汇总，并计入同一张发票。企业组织钱包没有每月赠送额度——所有 Token 消耗都完全按量付费，通过 Stripe 计量。
- 席位数量可以调整。新增的席位按比例计费。

**包含内容**

- 20+ 个并发工作流，可按需提高
- 共享的组织钱包和统一汇总的 Token 用量
- 用于访问控制的成员角色（所有者、管理员、成员）
- 按成员和按项目进行成本归属
- CI/CD 集成

**个人账户不受影响**。加入组织不会改变你的个人订阅、个人项目或个人钱包。两者的计费完全独立。完整说明请参阅[企业组织指南](enterprise-organizations.md)，包括项目归属如何决定计费，以及一个用户如何同时属于多个组织。

如需批量折扣或由销售协助开通，请通过 [sales@muggle-ai.com](mailto:sales@muggle-ai.com) 联系我们。
