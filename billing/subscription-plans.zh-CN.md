# 订阅套餐

Muggle Test 提供多个订阅档位，以满足你的测试需求。每个套餐都包含每个项目无限量的用户旅程和测试用例；用量以 Token 计量。

如需了解当前价格，请参阅[定价页面](https://muggle-ai.com/#pricing)或产品目录 API。

## 并发工作流

此项限制决定可以同时运行多少个工作流（扫描、测试生成、回放）。

| 套餐 | 并发上限 |
| :--- | :--------------- |
| 免费版 | 3 |
| 入门版 | 10 |
| 专业版 | 20 |
| 企业版 | 每个并发块 20 个，由整个组织共享 |

如果在已达上限时启动工作流，它会等待某个正在运行的工作流结束。等待时长请参阅[配额与限制](billing/quotas-and-limits.md)。

## 查看当前用量

在控制台中打开**账单**，即可查看你的 Token 余额和并发工作流用量。

## 每月 Token 赠送额度

套餐中包含的 Token 额度会计入你钱包的**赠送余额**。它在各档位中的规则如下：

- **免费版：** 免费版用户在注册时获得**一次性**的 200 万 Token 赠送额度。该额度**永不刷新**——用完后，可以改用入门版（向所有用户开放，验证邮箱后即可使用，每月补满至 150 万 Token），或升级到付费套餐。免费版用户没有每月重置。
- **入门版和专业版：** 每次 Stripe 订阅发票付款成功后，你钱包的赠送余额都会**补足到套餐额度**。上个周期剩余的赠送额度**不会**叠加到新一个月的额度上——赠送余额只会补足到套餐额度（绝不会减少）。你以充值方式购买的 Token 单独记录，永不过期。
- **企业版：** 组织钱包**没有**赠送额度。组织预先购买 Token，组织项目上的工作从该预付余额中扣除。
- **套餐升级：** 在周期中途升级时（例如入门版 → 专业版），Stripe 开具按比例计费的发票后，你的钱包会立即获得新旧套餐额度之间的**差额**（例如，在周期中途从入门版升级到专业版会计入 1850 万 = 2000 万 − 150 万）。降级**绝不会收回 Token**。
- **Token 消耗顺序：** 使用 Token 时，**先扣除赠送余额**，再扣除你购买的 Token 充值包。这对购买充值包的用户更公平，因为赠送的 Token 本来就可能在续订时被重置。

### 购买的 Token 充值包

如果你需要的 Token 超出套餐赠送的额度，可以在账单页面购买一次性的 Token 充值包。**以这种方式购买的 Token 永不过期**，并与套餐赠送额度分开记录在单独的余额中。更换套餐、续订和降级后，这些 Token 依然保留。

## 升级套餐

要提高上限：

1. 在控制台中进入**账单**
2. 选择**账单**标签页
3. 点击**更改套餐**
4. 选择新套餐

更改会立即生效，新的上限适用于所有现有项目。

## 企业版

企业版专为团队打造。你的公司会获得一个**组织**，拥有共享项目、一个预付 Token 余额和一个并发工作流池。在定价页面或控制台的**账单**页面上选择**创建组织**，然后在组织的**容量**页面上订阅；无需联系销售。

**定价**

- **贡献者席位：** 席位 1–10 每个席位每月 $29，席位 11–50 为 $24，第 51 个席位起为 $19，最少 **3 个席位**。每位所有者、管理员和贡献者占用一个席位；只查看的成员不占用席位。
- **并发块：** 每个含 20 个并发工作流的块每月 $99，最少 1 个。最多 3 个块可自助开通；更多需通过销售。
- **Token：** 预付，每 100 万 Token $5，每次购买 $100 起，支持自动充值。没有每月赠送额度。
- 新增的席位和块立即生效并按比例计费；减少在下次续订时生效。

**包含内容**

- 整个组织共享一个并发工作流池，共享运行器繁忙时优先启动
- 共享的组织项目和预付的组织 Token 余额
- 用于访问控制的成员角色（所有者、管理员、贡献者、成员）
- 按项目的并发上限和每月 Token 上限
- 按成员和按项目划分的用量
- CI/CD 集成

**个人账户不受影响**。加入组织不会改变你的个人订阅、个人项目或个人钱包。两者的计费完全独立。完整说明请参阅[企业组织指南](billing/enterprise-organizations.md)，包括项目归属如何决定计费，以及一个用户如何同时属于多个组织。

如需超过 3 个并发块或由销售协助开通，请通过 [sales@muggle-ai.com](mailto:sales@muggle-ai.com) 联系我们。
