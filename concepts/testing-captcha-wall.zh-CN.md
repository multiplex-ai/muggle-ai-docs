# 测试验证码后的流程

Muggle Test 会在运行过程中检测验证码，并自动完成常见类型的验证码，让登录和注册流程无需人工输入即可完成。

| 类型 | 支持 |
| :-------------- | :-------: |
| reCAPTCHA v2    |     ✅     |
| reCAPTCHA v3    |     ✅     |
| hCaptcha        |     ✅     |
| 图片验证码 |     ✅     |
| 滑块 / 音频 |     ❌     |

当某个验证无法自动完成时，运行会暂停并请求协助，而不是悄无声息地失败。

> 💡 在预发布环境中，尽可能关闭验证码——运行更快、更可靠。在生产环境测试中保持开启，以验证真实的用户体验。

完整的行为说明、支持的类型、回退流程和限制，请参见[自动处理验证码](automated-captcha-handling.md)。

## 指令示例

> “以新用户身份在 `localhost:3000/signup` 注册，如果出现验证码就完成它，并验证欢迎页面成功加载。”
