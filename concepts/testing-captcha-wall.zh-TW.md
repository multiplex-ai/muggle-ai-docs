# 測試驗證碼後的流程

Muggle Test 會在執行過程中偵測驗證碼，並自動完成常見類型的驗證碼，讓登入與註冊流程不需人工輸入即可完成。

| 類型 | 支援 |
| :-------------- | :-------: |
| reCAPTCHA v2    |     ✅     |
| reCAPTCHA v3    |     ✅     |
| hCaptcha        |     ✅     |
| 圖片驗證碼 |     ✅     |
| 滑塊 / 音訊 |     ❌     |

當驗證無法自動完成時，執行會暫停並請求協助，而不會在沒有任何提示的情況下失敗。

> 💡 在預備環境中，盡可能停用驗證碼——執行速度更快、也更可靠。在正式環境的測試中則保持啟用，以驗證真實的使用者體驗。

完整的行為說明、支援的類型、備援流程與限制，請參閱[自動處理驗證碼](automated-captcha-handling.md)。

## 指示範例

> 「以新使用者身分在 `localhost:3000/signup` 註冊，若出現驗證碼就完成驗證，並確認歡迎畫面成功載入。」
