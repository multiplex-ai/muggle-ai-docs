## 登入一直失敗

**症狀：**

- 測試無法通過登入頁面
- 報告顯示第一個步驟一再失敗

**診斷與解決方法：**

| 檢查項目 | 解決方法 |
| :------------------- | :----------------------------------------------------- |
| 基礎 URL 是否正確？ | 確認可從公開網際網路存取該網址 |
| 憑證是否為最新？ | 在專案設定的**登入憑證**中更新 |
| 是否啟用了 SSO/2FA？ | 改用未啟用這些功能的預備環境 |
| 帳戶是否遭鎖定？ | 重設測試帳戶，或建立新帳戶 |

## 網站掃描未找到頁面

**症狀：**

- 應用程式中的重要區域從未出現在候選流程中
- 已找到的情境中缺少關鍵功能

**診斷與解決方法：**

| 檢查項目 | 解決方法 |
| :----------------------- | :------------------------------------------- |
| 頁面是否可存取？ | 確認連結/按鈕能通往重要流程 |
| 需要更多起始網址？ | 新增更多網址（例如 `/app/dashboard`） |
| 缺少權限？ | 為測試帳戶啟用功能旗標 |
| 頁面需要身分驗證？ | 提供有效的憑證 |

## 測試結果不穩定

**症狀：**

- 同一個腳本有時通過、有時失敗
- 兩次執行之間沒有任何程式碼變更

**診斷與解決方法：**

| 檢查項目 | 解決方法 |
| :------------------------ | :------------------------------------ |
| 即時資料有變動？ | 使用穩定的測試資料或種子資料 |
| 有背景工作正在執行？ | 確認測試期間 UI 保持穩定 |
| 時序問題？ | 聯絡支援團隊，並附上失敗執行的連結 |
| 依賴第三方服務？ | 以 mock 或 stub 取代外部服務 |

## API 身分驗證錯誤

**症狀：**

- `401 Unauthorized` 回應
- `403 Forbidden` 回應

**診斷與解決方法：**

| 檢查項目 | 解決方法 |
| :--------------------- | :-------------------------------------------------- |
| API 金鑰是否正確？ | 確認金鑰與儀表板中的一致 |
| 金鑰是否已過期？ | 在**設定 → API 金鑰**中重新產生 |
| 環境是否正確？ | 檢查金鑰是否與目標環境相符 |
| 標頭格式是否正確？ | 使用 `Authorization: Bearer KEY` 或 `x-api-key: KEY` |

## 測試執行逾時

**症狀：**

- 測試一直無法完成
- 狀態卡在 `running`

**診斷與解決方法：**

| 檢查項目 | 解決方法 |
| :--------------- | :---------------------------------- |
| 網站是否有回應？ | 確認目標環境正常運作 |
| 測試太多？ | 分成較小的批次執行 |
| 網路問題？ | 檢查防火牆/代理伺服器設定 |
| 頁面負載過重？ | 簡化流程或延長逾時時間 |

## 報告未產生

**症狀：**

- 報告分頁沒有顯示任何資料
- API 傳回空白報告

**診斷與解決方法：**

| 檢查項目 | 解決方法 |
| :----------------- | :-------------------------------------- |
| 執行是否已完成？ | 等待狀態變為 `completed` 或 `failed` |
| 權限問題？ | 確認帳戶具有報告存取權限 |
| 最近有執行記錄嗎？ | 先執行測試，再檢視報告 |

## 驗證碼阻擋測試

**症狀：**

- 測試在含有驗證碼的頁面上失敗
- 代理程式要求使用者介入處理驗證碼

**診斷與解決方法：**

| 檢查項目 | 解決方法 |
| :-------------------------- | :-------------------------------------------------------------------- |
| 驗證碼類型是否受支援？ | 請參閱[自動處理驗證碼](concepts/automated-captcha-handling.md)，了解支援的類型 |
| 滑塊或音訊驗證碼？ | 目前尚不支援這些類型；可考慮在未啟用這類驗證碼的預備環境中測試 |
| 新的驗證碼實作？ | 聯絡支援團隊，並提供該驗證碼類型的詳細資訊 |
| 頻繁觸發驗證碼？ | 你的測試帳戶可能已被標記；試試新帳戶，或將 IP 加入白名單 |

**提示：** 如果可以，請在預備環境中停用驗證碼，讓測試執行更快、更可靠。

## MCP 與本機測試問題

### 找不到 Electron-app

**症狀：**

- 錯誤：「Electron-app not found」
- 測試執行立即失敗

**診斷與解決方法：**

| 檢查項目 | 解決方法 |
| :---- | :------- |
| 安裝是否完成？ | 執行 `muggle doctor` 檢查狀態 |
| 下載失敗？ | 執行 `muggle setup` 重試 |
| 網路遭封鎖？ | 檢查防火牆/代理伺服器設定 |
| 使用自訂執行檔？ | 設定 `ELECTRON_APP_PATH` 環境變數 |

### 下載失敗並傳回 404

**症狀：**

- 安裝失敗，並顯示「Download failed with status 404」
- 無法安裝 electron-app 執行檔

**診斷與解決方法：**

| 檢查項目 | 解決方法 |
| :---- | :------- |
| 版本是否已發布？ | 查看 [Releases 頁面](https://github.com/multiplex-ai/muggle-ai-works/releases) |
| 版本不符？ | 確認套件版本與可用的發行版本一致 |
| 開發版本？ | 從原始碼建置（請參閱[安裝與設定文件](local-testing/setup.md)） |

### MCP 工具沒有出現

**症狀：**

- AI 助理無法辨識 `muggle-local-*` 或 `muggle-remote-*` 工具
- 「Tool not found」錯誤

**診斷與解決方法：**

| 檢查項目 | 解決方法 |
| :---- | :------- |
| 套件是否已安裝？ | 執行 `npm list -g @muggleai/works` |
| 設定是否正確？ | 檢查你所用平台設定檔中的 JSON 語法 |
| 是否已重新啟動用戶端？ | 變更設定後，重新啟動你的 MCP 用戶端 |
| Node 版本？ | 確認已安裝 Node.js 22+ |
| 執行診斷 | 執行 `muggle doctor` 找出問題 |

### 瀏覽器引擎無法使用

**症狀：**

- 錯誤：「Browser engine not available」
- 測試執行停滯

**診斷與解決方法：**

| 檢查項目 | 解決方法 |
| :---- | :------- |
| 瀏覽器引擎是否已安裝？ | 執行 `muggle setup` |
| 連接埠衝突？ | 檢查是否有其他處理程序正在使用該連接埠 |
| 權限問題？ | 確認 electron-app 具有執行權限 |

### 身分驗證問題

**症狀：**

- 「Not authenticated」錯誤
- 雲端功能無法使用

**診斷與解決方法：**

| 檢查項目 | 解決方法 |
| :---- | :------- |
| 身分驗證狀態？ | 執行 `muggle status` 檢查 |
| 憑證已過期？ | 執行 `muggle login` 重新驗證身分 |
| 是否已設定 API 金鑰？ | 在你的 MCP 設定中指定 `MCP_API_KEY` |
| 網路問題？ | 檢查防火牆/代理伺服器設定 |
